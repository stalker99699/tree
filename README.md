# 📦 Project Archiver

Универсальный инструмент для упаковки и распаковки проектов в единый текстовый файл с полным сохранением структуры директорий.

## ✨ Возможности

- **Полная поддержка бинарных файлов**: изображения, архивы, документы, медиа, исполняемые файлы
- **Автоопределение кодировок**: UTF-8, CP1251, KOI8-R, Latin-1 и другие
- **Сохранение структуры**: воссоздаёт все папки и файлы в исходном виде
- **Кроссплатформенность**: работает на Linux, Windows, macOS
- **Единый файл**: весь проект в одном удобном `.txt` файле

## 🎯 Поддерживаемые форматы

### Бинарные файлы
- **Изображения**: `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.ico`, `.svg`, `.webp`, `.tiff`
- **Архивы**: `.zip`, `.tar`, `.rar`, `.7z`, `.gz`, `.bz2`, `.xz`
- **Документы**: `.pdf`, `.docx`, `.xlsx`, `.pptx`, `.odt`, `.ods`
- **Медиа**: `.mp3`, `.mp4`, `.avi`, `.mkv`, `.wav`, `.flac`, `.mov`, `.wmv`
- **Исполняемые**: `.exe`, `.dll`, `.so`, `.bin`, `.dat`
- **Базы данных**: `.db`, `.sqlite`

### Текстовые файлы
Любые текстовые форматы: `.txt`, `.py`, `.js`, `.html`, `.css`, `.json`, `.xml`, `.yaml`, `.md`, `.c`, `.cpp`, `.java`, `.rs`, `.go` и многие другие.

## 🚀 Установка

Никаких зависимостей не требуется! Скрипт использует только стандартную библиотеку Python.

```bash
# Просто используйте файл tree.py
python3 tree.py --help
```

## 📖 Использование

### Упаковка проекта

Создать архив текущего проекта:
```bash
python3 tree.py pack
```

Упаковать конкретную директорию:
```bash
python3 tree.py pack /путь/к/проекту
```

Указать имя выходного файла:
```bash
python3 tree.py pack /путь/к/проекту -o my_project.txt
```

### Распаковка проекта

Восстановить проект из архива:
```bash
python3 tree.py unpack my_project.txt
```

Распаковать в конкретную директорию:
```bash
python3 tree.py unpack my_project.txt -d /путь/куда/распаковать
```

### Примеры

```bash
# Упаковать текущую папку в backup.txt
python3 tree.py pack -o backup.txt

# Распаковать backup.txt в текущую папку
python3 tree.py unpack backup.txt

# Упаковать проект и сохранить в другом месте
python3 tree.py pack ./my_app -o /tmp/my_app_archive.txt

# Распаковать в новую папку
python3 tree.py unpack /tmp/my_app_archive.txt -d ./restored_app
```

## 🔧 Как это работает

1. **Упаковка (`pack`)**:
   - Сканирует директорию рекурсивно
   - Определяет тип каждого файла (текстовый/бинарный)
   - Текстовые файлы читаются с автоопределением кодировки
   - Бинарные файлы кодируются в Base64
   - Сохраняет всё в структурированный текстовый файл

2. **Распаковка (`unpack`)**:
   - Читает архивный файл
   - Восстанавливает структуру папок
   - Декодирует бинарные файлы из Base64
   - Сохраняет текстовые файлы в оригинальной кодировке

## 📝 Формат архива

Архив представляет собой текстовый файл со следующей структурой:
```
=== FILE: path/to/file.txt ===
[содержимое файла]
=== END FILE ===

=== FILE: images/logo.png [BINARY] ===
[Base64 закодированные данные]
=== END FILE ===
```

## ⚠️ Ограничения

- Размер архива примерно на 33% больше оригинала из-за Base64 кодирования бинарных файлов
- Для очень больших проектов (>1GB) рекомендуется использовать специализированные архиваторы
- Символьные ссылки не поддерживаются

## 🛡️ Безопасность

При распаковке скрипт создаёт файлы только внутри указанной директории. Путь выхода за пределы целевой папки блокируется.
